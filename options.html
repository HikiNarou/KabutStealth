Tentang

Kabut v3.0.0 — ekstensi MV3 untuk Edge / Brave / Vivaldi (Chromium ≥ 111). Semua data tersimpan lokal via chrome.storage.local; tidak ada telemetri, tidak ada permintaan jaringan keluar; tanpa izin "tabs" (v3 — permukaan privilese diperkecil). Lisensi MIT.

Arsitektur: injeksi world: MAIN pada document_start (sebelum skrip halaman), seed stabil per-domain (farbling ala Brave: session-token × eTLD+1), noise deterministik, WebRTC dua lapis (jaringan + JS + sanitasi SDP), sanitasi header via declarativeNetRequest, anti-deteksi tampering (toString/name/length native, shim Proxy di atas prototipe asli, makeBoundProxy untuk objek platform WebGPU, fallback senyap), farbling blob-worker + guard window.open + guard iframe pristin.

Batasan yang jujur: (1) worker ber-URL file & Service Worker halaman tetap tanpa farbling (blob-worker kini terlindungi; membungkus file asli tidak bisa dilakukan tanpa risiko merusak); (2) sidik jari TLS (JA3/JA4) & stack TCP tidak dapat diubah ekstensi — gunakan profil "Asli"/"Windows" agar konsisten, atau VPN/proxy untuk anonimitas jaringan; (3) fingerprint canvas dapat berbeda bila Anda juga mengaktifkan farbling bawaan Brave (dobel noise — nonaktifkan salah satu bila perlu); (4) innerWidth/innerHeight dibiarkan asli (volatile, bukan sidik jari perangkat).
